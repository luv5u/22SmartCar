# 如何运行
## 环境要求
- Python 3.8+
- 依赖：numpy（仅测试使用）、PyYAML

## 基本运行
```bash
python3 corr_tool.py --config config.yaml
```
--config 指定 YAML 配置文件路径（必填，也支持作为位置参数传入）。同时支持位置参数写法（可选）：
```bash
python3 corr_tool.py config.yaml
```

## 运行单元测试
```bash
python3 -m unittest discover -s tests -v
# 或
python3 tests/test_corr.py
```

## 示例输出
```bash
$ python3 corr_tool.py --config config.yaml
n = 5
mean_a = 3.000000
mean_b = 4.000000
r = 0.987654
```
其中 r = <数值> 一行是固定输出格式，便于脚本提取。


# 输入文件格式要求
## yaml 有哪些字段
|字段|是否必填|说明|
|----|----|----|
|input_csv|必填|待读取的 CSV 文件路径。相对路径以当前工作目录为基准；若在工作目录下找不到，会再尝试以配置文件所在目录为基准解析。|
|col_x|必填|第一列列名（数值列）|
|col_y|必填|第二列列名（数值列）|

## csv 需要什么列、列名规则
第一行为表头，需包含 col_x / col_y 指定的列名。示例（sample_data.csv）：
```csv
timestamp,sensor_a,sensor_b,note
2024-01-01 00:00,1,2,ok
2024-01-01 00:01,2,4,ok
2024-01-01 00:02,3,6,ok
```
要求：文件非空，且至少包含 1 行数据（实际参与计算需 ≥ 2 行，否则方差无意义）；参与计算的两列取值需可转换为浮点数；两列长度必须一致（同一 CSV 行内天然一致）；其它列（如 timestamp、note）不参与计算，可自由存在。


# 输出结果的含义
## n / mean / r 各是什么
|字段|含义|
|----|----|
|n|参与计算的有效样本对数（两列均非空的行数）|
|mean_a|第一列（col_x）的算术平均值|
|mean_b|第二列（col_y）的算术平均值|
|r|两列的 Pearson 相关系数|

## r 的取值范围怎么解读
取值范围为 -1 ≤ r ≤ 1。
r = 1 表示完全正线性相关（一列随另一列同比例增大）；
r = -1 表示完全负线性相关；
r = 0 表示无线性相关（不代表完全无关，可能存在非线性关系）；
|r| 越接近 1，线性相关性越强，越接近 0，线性相关性越弱。
特例：若某一列取值恒定（方差为 0），相关系数无定义，程序会打印可读错误并以非 0 退出码结束。
